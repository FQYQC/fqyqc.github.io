去年的这个时候，我在 Cursor 的帮助下构建了这个站点。那时的 Cursor 漏洞百出，我需要不断自行阅读代码、查阅 Hugo 文档，才能开发和维护各种功能。
今年 4 月，我正式开始工作。开始工作的第一周，我在同事的指导下实现了公司文档的 Agent 化管理，让 Agent 自行调研、总结和搜索公司文档。
就在刚刚过去的一周，利用公司的各类接口，我完成了全工作流的 Agent 化。Agent 能够访问文档、连接所有远程开发机、部署实验、训练模型并分析结果。最重要的是，我让 Agent 每天自行归纳我与它的所有对话，追踪我的全部工作。自此，我在公司内的所有行为都可以被集中管理。Agent 能够获取与我一样多的上下文，却比我做得更快、更好，思考更全面，行为也更完备。

前几天，我看到一篇与我最近的想法一致的文章。它认为，AI 在大幅提高员工工作效率的同时，事实上并没有减轻员工的任何负担。在使用键盘编码的古代，如果一个程序员少工作 2 个小时，项目的交付周期大概也只会延长两个小时。但在今天，如果睡前没有告诉 Fable 5：“请你想尽一切办法提高模型的准确性”，并让它开始一整晚的自动迭代，似乎就会觉得这一觉白睡了，没用完的每周额度更是浪费了。

在 Agent 疯狂提高我工作效率的同时，AI 的魔爪也逐渐伸向我的生活。起初，我只是发现自己再也不敢在生活中作出任何抉择，就像我在工作中已经不敢手写任何一行代码一样。我担心自己的记忆、知识和思考是片面的、盲目的，甚至是错误的；我需要 AI 告诉我一个客观、正确的结果。在所有与 Claude 的非工作对话中，我最频繁的两类问题是“冰箱里放了这么久的食物还能不能吃？”和“我这痛那痛是不是病？”。逐渐地，我开始询问：“今天要不要拖地？”“180 个鸡蛋卖 10.99 是不是够便宜？”以及“工作午餐想提前离席该怎么说？”。我感觉自己正在与 AI 互相蒸馏：我希望它尽可能掌握我的人生；每当人生中出现一项新任务，我也会寻求它的指引，并试图将解决方法总结成我的 Skill。

为了进一步提高生活效率，我开始尝试将自己的生活总结为各种各样的 SOP。事实上，在此之前，我的生活，尤其是在美国的生活，几乎已经是 SOP 的集合：每天洗澡时收听固定的节目；每周五下班后去 Costco 购买相同的沙拉和熟食；每周末打扫卫生、清洗衣物，并针对三种不同类型的衣物使用三种不同配比的洗涤剂。这些早已是成熟的 SOP。然而，我并不满足于此。我希望拥有一个 AI 控制中枢，获取与我完全一致的上下文，并在陌生任务出现时为我提供足够细致的解决方案。例如，近期我需要它告诉我回国前要做的所有准备，向我透露诸如“降低车险保额”之类的省钱小妙招；更重要的是，详细指导我如何准备行李，告诉我应该在什么时刻把什么物品放进行李箱的什么位置。

但这究竟是什么？或许只有每次坐上回国的飞机，置身于一个睡眠崩溃导致激素紊乱、噪声巨大却又极度安静，当然最重要的是无法刷短视频的环境中，我才有时间思考。这种现象在工作后更甚。毕竟，我花费大量时间工作，又企图通过大量运动唤醒这副沉重的身躯，更需要充分的娱乐来维持存活。

我听过一些来自传统行业从业者的观点——比我从事的搜广推更传统的行业。这些观点的核心是，AI 无法取代人类。起初我也这样认为，但我在开始工作的这三个月里，完成了从质疑 AI 到几乎信仰 AI 的彻底转变。由此，我开始思考两个关键的问题：

其一，当 AI 不仅替代我的工作，也开始替我生活时，我该如何保有独立思考与自主选择的能力，以及某种真正的独特性？

其二，如果生产不再需要我的参与，我能凭借什么确认自己的价值，又应当把时间和生命投向何处？

或许我应当更为乐观地看待这些问题。正如我多年前写下的那样，AI 到头来也只是工具。AI 在我的生活中，也不过是取代了搜索引擎和知识问答平台。只是因为它更加快捷、方便，我对这类工具产生了空前的依赖。生活不一定需要正确，问题也并不总是渴求答案，人的价值也未必只能由产出来证明。如果有一天，工作真的不再构成自我证明的主要方式，我需要学习的也许不是寻找下一种更难被替代的生产，而是接受有些时间和关系本来就不需要被转化为产出。

这两个问题也让我开始重新衡量过去的一些选择。过去数年，我在电脑前耗费的心力，或许还不如在健身房和运动场上的付出来得可靠，因为 AI 或许能替代我的劳动，却终究无法替我感受和使用这副身躯。

![唯一不能交给 Agent 的任务。（图像由 GPT Image 2.5 生成）](/assets/local-assets/posts/what-ai-brings-us/01-pull-up.jpg)

或许现在的科研也已经不再那么痛苦。学生们早早地成为了导师：发布任务、审阅结果，利用自己的学术直觉找出其中的漏洞，再要求 Agent 检查并修改。这样便无需整夜在工位上困扰于繁杂的技术障碍，转而可以从容地提出问题、追随直觉、探索未知。想到这里，我又生出一丝侥幸。毕竟，这种难以形式化、甚至无法被完整解释的“直觉”，恰恰是越新的模型越谨慎对待的东西；人类在此似乎还能发挥一些作用。

就在我写这篇废话的同时，我让目前最先进的 GPT-5.6-sol 完成了这个站点面向 Agent 的现代化改造。
